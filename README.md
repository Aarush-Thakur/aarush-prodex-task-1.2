Further applications:

Stationary solar panels waste a lot of energy which could've been utilized, simply because they weren't aligned the right way. Using this project, a large amount of free, renewable energy can be utilized which was discarded before. Moreover, it also has applications in other fields, like aligning antennas and satellite dishes towards the strongest signal, if we switch out the photoresistors for other, more suitable sensors.
